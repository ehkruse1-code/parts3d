# Parts3D — Alternator Rebuild

A car alternator rebuilt as a measured 3-D CAD model from three catalog photos, viewable and rotatable in the browser.

**Live site:** https://ehkruse1-code.github.io/parts3d/

- `index.html` — the page (three.js viewer, loaded from jsDelivr)
- `alternator.glb` — the model (metres, Y up, named parts, PBR materials)
- `photo-front.jpg`, `photo-side.jpg`, `photo-back.jpg` — the three source photos
- `photo-vs-model.jpg` — each photo beside the model from the same camera
- `camera-views.jpg`, `other-angles.jpg` — renders of the model
